直接起草中国大陆商业合同，覆盖采购、服务、营销、工程施工、软件许可、SaaS、委托开发、联合研发、知识产权、租赁、数据处理和保密等场景。读完题干和附件后先拆交易信息、识别风险，再用起草方标准条款与受控的默认商业参数补足付款天数、验收期、违约金、责任上限、质保期等。产出无批注、无颜色、中文字体正确的可编辑 Word 文件，不编造主体、标的、金额和绝对日期。涉及跨境交易、境外法域或境外争议解决安排时主动升级并要求复核。

## 🇬🇧 English

Drafts mainland-China commercial contracts directly across procurement, services, marketing, construction, software licensing, SaaS, commissioned development, joint R&D, IP, leasing, data processing and confidentiality. It reads the brief and attachments, decomposes the deal, identifies risks, then fills drafter-standard policy clauses and controlled default commercial parameters such as payment days, acceptance windows, penalties, liability caps and warranty periods. Output is an editable Word file with no comments, no colour and correct East Asian fonts, with no invented parties, subject matter, amounts or calendar dates. Cross-border or foreign-law arrangements escalate for review.

### ✨ What it does

- Thirteen scenario families: procurement, services, marketing, construction, licensing, SaaS, development, joint R&D, IP, lease, data processing, confidentiality and more
- Every fact tagged confirmed, derived, standard_term, standard_parameter, pending or disputed
- Skeleton families plus scenario modules, so payment, acceptance, IP and signature terms never duplicate
- Controlled defaults written straight in: payment milestones, acceptance window, delivery periods, penalties, liability cap and warranty term
- Four scripted delivery gates run in order: preflight, consistency, policy and font check, none allowed to fail
- Handover separates confirmed facts with sources, prefilled parameters, remaining blanks and negotiation-sensitive items
